### 🎉 v1.0.0 - 首个版本，Modbus 电表正式登场！

从零构建的字典驱动电表接入框架，首发支持正泰 DDSU666。

### 🚀 核心提升：

#### 字典驱动多型号架构：
- 每款电表型号对应一份 `MeterProfile` 寄存器档案（块地址 / 数据点偏移 / 缩放 / 精度），协调器与传感器平台全量由字典驱动，新型号零侵入接入。
- 首发型号：正泰 DDSU666（Chint），8 个数据点全量实现：电压、电流、有功功率、无功功率、视在功率、功率因数、频率、总有功电能。

#### 两级配置流：
- 一级选择电表型号（下拉框），二级配置连接参数（连接名称 / IP / 端口 / 从机地址）。
- 连接名称默认继承型号名；多表重名自动追加从机号；条目标题 = `host:port`，设备名与条目身份解耦。

#### 运行时治理：
- 轮询间隔（最小 5 秒）经 Options Flow 在线调整，保存自动重载，无需重启。
- 支持「重新配置」：修改型号与连接参数后自动重载生效。
- 块级容错：单寄存器块失败仅告警降级，其余数据点不受影响。
