# 使用指南 (Documentation)

---

## ⚙️ 配置 (Configuration)

### 步骤 1：选择电表型号（一级界面）

> 集成安装方法见 [README](../README.md#-安装)。

- **电表型号**：下拉选择框。当前支持 **DDSU666**（正泰 Chint），后续型号随寄存器档案扩充。
- 选择后进入连接参数界面。

### 步骤 2：连接参数（二级界面）

通过 Modbus TCP 连接电表（可经串口服务器 RTU 转 TCP），需先在表内开启通讯：

| 字段 | 说明 |
| :--- | :--- |
| **连接名称** | 设备名称，默认继承电表型号（如 `DDSU666`）。**同网关挂多块表时请改名区分**；若留空且与其他条目重名，系统会自动追加从机号（如 `DDSU666 #2`）。 |
| **IP 地址** | 电表或串口服务器（485 转 WiFi/以太网）的 IP 地址。 |
| **Modbus TCP 端口** | 默认 `8899`，以串口服务器实际配置为准。 |
| **从机地址** | 电表 Modbus 从机地址，默认 `1`。单网关多表时，各表的从机地址需在表内设置为不同值。 |

- 提交成功后，条目标题显示为 **`host:port`**（如 `192.168.51.22:8899`），设备名称取连接名称，两者解耦——多表场景下实体 ID 由连接名称保证唯一。

### 步骤 3：选项设置 (UI Options)

集成添加后，在 **设置 > 设备与服务 > Modbus 电表** 条目上点击 **“配置”**（Options），可实时调整：

- **轮询间隔（秒）**：数据轮询周期，**最小 5 秒**。保存后立即生效并自动重载，无需重启 HA。

### 重新配置 (Reconfigure)

在条目菜单中选择 **“重新配置”**，可修改电表型号与全部连接参数（连接名称 / IP / 端口 / 从机地址），保存后自动重载生效。

## 🌐 连接拓扑

| 拓扑 | 说明 |
| :--- | :--- |
| **Modbus TCP 直连** | 电表本身带网口（或 WiFi），直接填电表 IP 与端口。 |
| **串口服务器中转** | 电表为 RS-485 接口，经串口服务器（485 转 WiFi/以太网）转为 Modbus TCP。IP 填串口服务器，从机地址填电表地址。 |

单台串口服务器可挂多块表：各表设置不同从机地址，在 HA 中为每块表添加一条集成条目，用连接名称区分设备。

## 📈 前端展示建议

### 单日/单月耗电量

集成提供的是累计电能，按周期分段统计请使用内置的 `utility_meter` 辅助元素（无需本地计算）：

1. **设置 > 设备与服务 > 辅助元素 > 创建辅助元素 > 公用事业表**（utility_meter）
2. 输入源选择 **总有功电能** 实体，周期选 **日**（或月/年）
3. 生成 `sensor.xxx_daily_energy`，每日 0 点自动归零

### 能源面板

`总有功电能` 实体为标准 `total_increasing` 能量传感器，可直接添加到 **能源 > 电力** 面板。

## 💡 常见问题 (FAQ)

#### Q: 功率因数实体为什么没有单位？
#### A: 这符合 Home Assistant 官方规范——功率因数设备类仅允许「百分比」或「无单位」两种呈现，集成选择了无单位（数值 0~1），属于正确行为而非缺陷。

#### Q: 为什么有功功率是负数？
#### A: 负值表示当前功率方向为反向（如光伏馈电回电网）。本表为单向计量，电能实体只累计正向（消耗）电量。

#### Q: 电表实体间歇性「不可用」？
#### A: 多为 485 转 WiFi 串口服务器的网络链路抖动。排查顺序：串口服务器信号强度 → 电表供电与通讯参数（波特率/校验位需与串口服务器一致）→ 轮询间隔是否短于串口服务器响应能力。集成采用块级容错，单块寄存器读取失败不会导致其余实体失效。

#### Q: 如何接入第二块表？
#### A: 再次添加集成条目即可。同一串口服务器下：从机地址填电表实际地址，连接名称改成可区分的名字（如 `DDSU666-客厅`）；不同串口服务器则各自填 IP。条目间通过 `host + port + slave` 与连接名称防重复。
